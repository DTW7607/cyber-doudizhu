# 斗地主架构

此分支仅运行三人斗地主。仓库保留上游其他规则/素材及测试作为来源记录，入口不会加载它们。

| 文件 | 职责 |
| --- | --- |
| server.js | HTTP/静态文件、WebSocket 限流/心跳、健康检查、优雅退出 |
| runtime/tables.js | 同名身份、单会话、三席生命周期、请求去重、视角广播、持久化事务 |
| runtime/state-store.js | v1 快照校验、0600 临时文件、fsync、原子改名；坏数据拒绝启动 |
| games/doudizhu.js | 规则、牌型、轮次、叫分/叫抢、结算与延长投票 |
| public/js/ddz-shell.js | 一个连接管理登录/大厅/牌桌，回执与重连、模态框、排行榜 |
| public/js/session-store.js | 浏览器成功登录历史；每标签页令牌隔离与会话缓存 |
| public/js/renderers/doudizhu.js | 手牌排序/重叠/拖选、预选、回合与牌局状态渲染 |
| mcp/server.js | 每进程一个普通玩家，与浏览器相同权限与协议 |

## 一次操作

WebSocket 请求 → 校验身份和请求编号 → 校验 revision、规则/席位 → 修改内存 → 保存快照（文件 fsync、rename、目录 fsync）→ 过滤手牌并广播 → action_result。

失败写盘不发成功消息，关闭服务交由 supervisor 从最后快照恢复。同一连接保留最近 64 个请求结果；相同 requestId 与内容重放只重发结果，内容冲突则报错。跨连接不自动重放动作。客户端收到不确定结果须查看最新状态。

## 身份和座位

昵称以 NFKC、合并空白、忽略大小写匹配。按昵称登录是产品约定，不能用于认证现实身份。一次登录轮换令牌，撤销旧连接。按令牌自动恢复失败后必须显式选择用户。登录页只展示本浏览器成功记录，服务端没有用户目录接口。

断线只改变在线状态，不释放席位；主动 leave_room 才释放。游戏状态手牌/积分按席位保存，仍有占用席位时补位沿用。少于三人在线时拒绝出招。host 从在线成员中选出，离线全员的房间继续保留。最后一名玩家主动离桌后，删除房间并通知观众；启动时清理旧版本遗留的零席位房间，保留所有有占用席位的房间及身份。

状态文件仍为 version 1：identities、rooms、房间 state 和 players。房间 revision 与 state.dealNumber 是可选新增字段。重启只把原有占用席位置为离线，不改手牌、当前行动者、分数、局数或记录。

## 连接和视图

状态中的 hands 与 board.hands 均按玩家过滤，未确定地主前底牌隐藏。客户端只基于回执解锁操作，其他玩家的广播不能代替回执。心跳与渐进重连保留座位，不代打、不踢人。

服务默认监听 127.0.0.1:3000。可通过 HOST、PORT 环境变量配置监听地址和端口。普通 MCP 默认 stdio，可选 HTTP 仅监听 127.0.0.1，不增加公网端口。
