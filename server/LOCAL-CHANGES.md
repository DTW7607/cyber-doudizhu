# 斗地主 2.3.0-landlord.2

2026-11-13 审查版本。基于 GameNest，保留 Apache-2.0、LICENSE、NOTICE 及原有角色素材。此仓库提供通用源码与运行说明，不包含本地部署记录。

## 改动

- 将线上仅需的斗地主运行逻辑从通用多游戏服务器拆为传输层、牌桌/身份层和原子状态存储层；没有接入机器人或特权玩家。
- 所有成功回执与状态广播在持久化完成后发出；文件和目录均 fsync。错误状态拒绝启动，不能静默覆盖用户数据。
- 同名身份复用、令牌轮换、旧会话撤销。旧标签页在 sessionStorage 固定自己的令牌，即便休眠期间漏掉踢下线事件，刷新也不能借用新标签页登录。
- 请求编号防止重复执行；牌局 revision 拒绝过期出牌；客户端超时显示未确认并重新同步，不自动重放。
- 断线保留座位，主动离桌释放席位并保留手牌/积分；补位原样继承。修复所有其他玩家离线时房主离开后无人可开局的问题。
- 离桌清除该席位延长投票，state 与 board 视图一致；拒绝重复/畸形牌 ID。保留春天、反春天、128 上限和末局三人一致加 3 局。
- 单 WebSocket 负责大厅、身份和牌桌；移除大厅额外加载的通用多游戏客户端。统一 CSS，圆桌展示三个席位/昵称/状态。
- 稳定手牌 DOM，支持非本人回合预选、触屏拖选、键盘选牌；按大小左排、重叠无横向滚动，选中上移约牌高三分之一。
- 增加持续连接状态、暂停/补位提示、三席积分、回合标记、排行榜、规则和回合音效开关。
- MCP 逐请求等待服务器回执；不会把其他人的广播或超时当作操作成功。断线/暂停能结束等待；按普通玩家视角屏蔽其他手牌。

## 验证入口

```sh
npm ci --ignore-scripts
npm --prefix mcp ci --ignore-scripts
npm run check
npm test
node scripts/verify-migration.js /private/copied-state.json
```

迁移脚本只在临时副本上登录并重启，原文件不变。自动化包含规则、隐藏牌、会话抢占、主动离桌/断线、竞争补位、投票、写盘失败、v1 迁移、完整对局、浏览器 DOM 与 MCP。真实浏览器尺寸/触屏模拟另行验收；DOM 测试不等同于实机测试。

## 数据与回滚

状态保持 version 1，新增字段 revision/dealNumber 为可选。生产部署流程、路径与回滚说明见 `docs/OPERATIONS.md`。不在代码目录保存线上令牌或真实状态备份。
